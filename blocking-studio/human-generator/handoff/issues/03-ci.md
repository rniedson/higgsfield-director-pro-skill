Part of TRACKING.

`.github/workflows/tests.yml` runs `node --expose-gc --test blocking-studio/human-generator/tests/test_generator.mjs`
only, so every pull request into `procedural-hands` fails CI until the heap test passes (its own issue in TRACKING).
The branch adds two more suites and a generated file that must stay in step with the code:

- `blocking-studio/human-generator/tests/test_hands.mjs`
- `blocking-studio/human-generator/tests/test_hand_dna.mjs`
- `node tools/fit_hand_poses.mjs --check` (run from `blocking-studio/human-generator/`): says whether
  `hands/fit.js` is what the tool would write for the current poses and mesh. It exits non-zero when it is not.

## What to do

- Add the two suites and the fit check to the Node job, with `--expose-gc` (the performance and memory tests use
  it), on the same Node version as today.
- Time the job. The hand suites took about a minute on a laptop; if the job gets much slower, say so in the pull
  request rather than skipping tests.
- Update the "Run the checks" block of `CONTRIBUTING.md` with the same commands.

## Done when

CI fails when a hand test fails or when `hands/fit.js` is out of date (try both on a throwaway commit), and passes
on the branch once TRACKING's test fixes are in.
