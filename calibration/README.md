# Calibration records

Each file is one blind round: the same request made with and without the skill, and a person choosing without
knowing which was which. The rounds below were run by the maintainers while the skill was built, with one voter.

They are kept as a record, not as a promise. After the fifth round, on 2026-11-26, the maintainer decided that the
skill's work is the process (one step at a time, a cheap preview before each expensive step, every credit in view),
not out-doing what the models give a plain request: across nine rounds, the version whose prompts the skill rewrote
was chosen in four. The READMEs no longer report the rounds, and the skill runs a blind test only when the operator
asks for one ([`calibration.md`](../higgsfield-director/references/calibration.md)).

## The rounds

The same requests were made with and without the skill, from 2026-11-24 to 2026-11-26. Every round is here as it
came out, the losses included.

**1. Planning: 18 automated Claude Code sessions, 9 with and 9 without the skill, with no credits spent.** There were
5 requests (a 3-shot commercial, a "go ahead and generate", product photos, a creator video and a single image), with
the generation tools blocked.

- For product photos and the creator video, both conditions picked the connector's ready-made workflow: the skill
  does not get in the way of what the connector already does.
- 17 of the 18 sessions got a quote from the connector before proposing a generation. The other one, without the
  skill, stopped before quoting when it noticed the generation tools were blocked.
- With the skill, the work took 34% longer overall (753 s against 564 s), and about 40% longer for a single image.
- **What could not be measured:** whether the skill prevents "spending without asking for an ok". With the generation
  tools blocked, no session could spend.

**2. The first round, with the skill `5.1.0+982e7fa`: the generated commercial, judged blind (6 shots of 5 s, 90 credits).** It was a 3-shot running shoe
commercial: material detail, a run on a wet track at night, and the product as the hero at the end. Each condition's
prompts were generated on Cinema Studio 4.0 at 480p with sound, and the two videos got shuffled labels (X and Y). An
automated judge that saw only the request and the videos scored them, and a person voted without knowing which was
which.

| | With the skill | Without the skill |
|---|---|---|
| Blind judge score (0–100) | 70.7 | 71.3 |
| Camera (0–10) | **8.7** | 7.3 |
| Light (0–10) | **8.7** | 7.0 |
| Product identity (0–10) | 5.0 | **6.3** |
| Materials (0–10) | 7.7 | **8.3** |
| The person's blind vote | | **chosen**: "for the movement, action, emotion, sound" |

**It was a tie, and the person preferred the version made without the skill.**

- **Where the skill helped:** one clean camera move per shot and steady light. Without it, the model cut one shot into
  three on its own, and the last second came out blurred and blown out.
- **Where it lost, because of its own rules:**
  1. **Prompts that were too restrained.** A sliding water drop and a sideways slide looked correct and flat next to a
     fingertip pressing the knit, slow-motion splashes and a bass hit on the final frame.
  2. **Camera move against end state.** The text asked for a push-in to a close-up and for the whole product at the
     end. The model followed the move and cropped the product.
  3. **Product described in text only.** In a close-up of the knit alone, the model drew a shoe with no laces. Both
     conditions warned about the risk, but neither proposed generating a product reference image first.

The three points became rules in this version ([prompt](../higgsfield-director/references/prompt.md),
[quality](../higgsfield-director/references/quality.md)).

**3. The rematch, with the fixed skill `5.1.0+e4dee7b` (2 rounds, 152 credits).** With the three fixes in, the same method ran again,
with its own X and Y draw in each round. Round 1 was the same running shoe commercial, now with the same product photo
in both conditions (generated first, for 2 credits). Round 2 was a 3-shot 16:9 trailer: a lighthouse keeper on a
stormy night. The connector's copyright filter rejected the middle shot in both conditions, with no charge, so the
comparison uses shots 1 and 3.

| Round | Blind judge score, with the skill | Without the skill | The person's blind vote |
|---|---|---|---|
| 1 · running shoe commercial, with the product photo | **82.5** | 73.8 | with the skill |
| 2 · lighthouse trailer (shots 1 and 3) | **78.0** | 69.8 | with the skill |

**The person chose the version with the skill in both rounds**, "for the whole: how one scene connects to the next,
more organic". The blind judge, which scored each version per criterion with evidence, chose the same.

- **What decided it, according to the judge.** In round 1, with the skill the shoe from the photo stayed the same in
  all three shots, and the night stadium ties the first shot to the last. Without it, the model gave the shoe a sole
  that lights up blue and showed the white shoe as grey: in an ad, that is showing a different product. In round 2,
  without the skill shot 3 had two cuts nobody asked for, and the boat changed design halfway through.
- **What is still missing.** Sound: both conditions came out quiet (−22 to −32 LUFS, against about −14 for social
  platforms) with level jumps between shots. And, with the skill, the lighthouse's bands changed between shots and the
  colour drifted from cold to warm.

**Caution, raised by the person who voted:** in both rounds the version with the skill drew X and was shown first, on
the left, and "having seen it first may also affect the choice". Two rounds cannot separate that effect. So `hfd.py
blind` now draws, separately, which version is shown first, and the record keeps the order so the scoreboard can
measure it. The sample is still small: three rounds and one voter.

**4. The third round, with `5.1.0+7b60cfa` (2 rounds, 150.24 credits).** Two request types not
measured before, with the order of showing drawn on its own: the version with the skill was shown first in round 1,
the one without it in round 2. Round 1: a 10 s fight scene in one shot, a fighter against a robot, from a start image
each condition designed (Seedance 2.5, 480p, with sound). Round 2: a 3-shot
corporate video for a school (Cinema Studio 4.0, 480p, 5 s per shot, with sound).

| Round | Blind judge score, with the skill | Without the skill | The person's blind vote |
|---|---|---|---|
| 1 · fight scene, one 10 s shot | **77.5** | 60.0 | without the skill |
| 2 · corporate video, 3 shots | **72.0** | 62.0 | without the skill |

**The person chose the version made without the skill in both rounds; the blind judge chose the version with it in
both.** The person's vote is the criterion, so the round counts against the skill.

- **What the person said.** Round 1: the version without the skill was much better in movement, atmosphere, sync
  and characters. Round 2: the version without the skill looked natural, "as if it was not made with AI"; the one
  with it looked fake, with three teenagers sharing one face and sound like the stock audio of social media.
- **What the judge saw.** In round 1, with the skill the robot stayed the same robot and every blow read clearly, but
  the fight was over at about 6.5 s and the last 3.5 s held still; without it, the fighter took a longer, heavier
  beating, while the robot changed design several times. In round 2, with the skill the clothes carried across the
  three shots and nothing was cut that nobody asked for, but three students shared one face and the teacher barely
  guided anyone; without it, the first shot was the liveliest of the round, with two cuts nobody asked for.
- **Why, read in the prompts after the vote.** The version with the skill had turned recipes against defects into
  lines in every prompt (constant light and exposure, a camera at constant speed, one continuous motion): the fight
  was over at 6.5 s of 10, and the place had no flickering lamp, rain or haze. It described the class in one line,
  posed the group toward the camera, and asked for interface chimes and a line of dialogue nobody requested. The
  version without it gave the fight in timed beats up to 10 s, moved the camera with the action, gave each student
  a line of their own and kept the sound of the place. Most of those rules entered the skill after
  `5.1.0+e4dee7b`, from tutorial lessons.
- **What changed.** A recipe against a defect now goes in after the defect is seen; a long shot is written in timed
  beats up to its end; each person in frame gets a line of their own; a piece about real life keeps a documentary
  register and the place's own sound ([lessons](../lessons-learned/2026-11-own-runs.md)). One round per request type
  says which video won, not which line made the difference: the next blind round measures the change.
- **The blind judge disagreed with the person in both rounds.** Its criteria weigh control (identity, camera and
  continuity are 45% of the score), and none asks whether the video looks natural. Its scores stay in the records
  as a second opinion; the person's vote decides.

**5. The fourth round: the retest with the fixed skill `5.1.0+0717197` (2 rounds, 150.24 credits).** The same two
requests as section 4, with new videos and new draws on both sides; the version without the skill was planned again
too. The version shown first was the one with the skill in round 1 and the one without it in round 2.

| Round | Blind judge score, with the skill | Without the skill | The person's blind vote |
|---|---|---|---|
| 1 · fight scene, one 10 s shot | 58.0 | **76.5** | **with the skill** |
| 2 · corporate video, 3 shots | 70.5 | **73.5** | **with the skill** |

**The person chose the version made with the skill in both rounds**, in round 2 against the order of showing: "The
most natural: no errors, hallucinations or artificial gestures; could pass for real footage."

- **What the fix did.** The prompts with the skill carried no defect recipe. The fight was written in timed beats up
  to 10 s, with a camera that followed it, a flickering lamp, rain and haze. Each student and the teacher had a line
  of their own, in a documentary register, with the sound of the place.
- **What it did not fix.** In round 1 the start image made with the skill lost the premise: the robot came out with
  a blank chrome head instead of the fighter's face. A production would catch that on the review page; a blind round
  generates what comes. In round 2 the model stitched two cuts nobody asked for into the first shot, at about 2.2 and
  3.7 s (the other side had the same in section 4), and small white crests appeared on some shirts in the last shot,
  although the request said no brand.
- **The blind judge chose against the person again, in both rounds**, this time for the version without the skill:
  it weighed the blank robot head and the extra cuts. Asked separately which version looked more natural, it agreed
  with the person in round 2 and not in round 1. In the last four rounds its score never picked what the person
  picked; its criteria do not ask whether the video could pass for real footage, which is what the person judged on.
- **What it does not show.** One round per request type says which video won, not which rule made the difference.
  The version seen first was chosen in 4 of 6 rounds with the order recorded.

**6. The fifth round: two new requests, with `5.1.0+0f8bcfb` (2 rounds, 196.5 credits).** The skill as it stood after
section 5, on two requests it had not seen. Round 1: a 3-shot commercial for a neighbourhood bakery's opening (Cinema
Studio 4.0, 480p, 5 s per shot, with sound); the version with the skill animated three start frames it designed, the
one without it wrote text to video. Round 2: a 3-shot teaser for an invented short film, a grandmother teaching her
grandson to fish on a river at dawn (Seedance 2.5, 480p, with sound), both sides from reference images. The draw
showed the version with the skill first in round 1 and the one without it first in round 2.

| Round | Blind judge score, with the skill | Without the skill | The person's vote |
|---|---|---|---|
| 1 · bakery commercial, 3 shots | 53.0 | **74.5** | **without the skill** (blind: with the skill; changed after the key) |
| 2 · fishing teaser, 3 shots | **81.0** | 71.5 | **without the skill** |

**The person chose the version made without the skill in both rounds.**

- **Round 1: a sign the request had ruled out.** Blind, the person chose the version with the skill, the more natural
  one. After the key, they learned that its last shot shows a wooden sign with a bakery's name, on a street that looked
  foreign, and changed the vote: "if it was in the prompt, it should not be there". The request said no brand and no
  text on screen. The prompts with the skill had left that out: the start frame's prompt asked only for "a plain
  unlettered awning", and the image model wrote a name on a sign above it. The prompts without the skill said "No
  text, letters, numbers, logos or brand names anywhere" and named the signboard as blank, and the same video model
  left it blank. The model also stitched two cuts nobody asked for into that last shot.
- **Round 2: people who looked like models.** "More natural; they look more real." With the skill, the grandmother
  and the boy came from studio character sheets, with a shirt tucked in under a belt and a plain new T-shirt; they
  were already standing at the water when the shot opened, and the last shot was a glossy laugh against the light.
  Without it, one picture made on the riverbank gave them a frayed straw hat, a skirt, rubber boots and a tin of bait,
  and they walked into the frame. The blind judge's score preferred the version with the skill; asked which looked
  more natural, it chose the one without, like the person. The connector's content filter refused one shot of the
  version with the skill, with a refund; the same request, sent again unchanged, passed.
- **What changed.** The request's own limits (no text, no brand, nobody real) now go into every image and video
  prompt in plain words, naming the surfaces that stay blank. The other differences stayed as lessons
  ([lessons](../lessons-learned/2026-11-own-runs.md)): the same day, the skill stopped adding to the prompts what the
  request did not ask for (the top of this page).
- **What it does not show.** One round per request type. Blind, the version seen first was chosen in 6 of 8 rounds
  with the order recorded; counting the changed vote, 5 of 8.

## How to add yours

1. Run a calibration: [`calibration.md`](../higgsfield-director/references/calibration.md).
2. Build the record with `hfd.py result ... --out calibration/YYYY-MM-DD-<category>-<suffix>.json`, then read it
   in full before sharing it.
3. Run `python3 tools/aggregate_calibration.py --write` to refresh the scoreboard on this page, then
   `python3 tools/check_repo.py`.
4. Open a pull request with the record and this page's change. See [CONTRIBUTING](../CONTRIBUTING.md).

The record holds only the allowlisted fields (date, skill version, request type, model, shots, credits, whether a
reference image was used, the vote, the order seen, an optional short reason and the reviewer's scores). It never
holds the request text, prompts, media, names, clients, brands, links, e-mail addresses or file paths; CI rejects any
other field.
