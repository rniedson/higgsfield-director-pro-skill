Higgsfield Director PRO

Direct AI-generated video one step at a time: plan, preview and price every shot before spending a credit.

View on GitHub Illustrated manual

How it works

1

The plan

The idea, the shots, the model and the prompts, in words. Costs nothing. Change it while it is free.

2

One still per shot

A cheap image of each shot. A few credits. Check the look, the people and the place.

3

One test shot

The riskiest shot as a short video at the lowest resolution. Check motion and sound.

4

The rest

The other shots, then the final resolution if you want it. Only the total you approved.

Why use it

Nothing spent by surprise

Every generation is quoted first and waits for your ok. After each one you see what it cost and the total so far.

Mistakes caught early

One still per shot, then one test shot at the lowest resolution, before the rest.

Your request stays yours

Every fact and limit you give goes into the prompt as you said it. Camera and light come in only when you ask.

Errors found before any credit

hfd.py validate checks model limits, dialogue, continuity and the 180-degree axis, offline and free.

Today's prices, never stale

No price is written in the skill. The day's price table comes from the connector's free quotes.

Your way of working

Approve every step, give one ok for the total, or set a ceiling for the session.

Quick start

Requires Claude Code and/or Codex, Python 3.9+. For generation, a Higgsfield account.

# Clone and link the skill to your project git clone https://github.com/rniedson/hfd.git R="$PWD/hfd/higgsfield-director" cd /path/to/your/project mkdir -p .claude/skills && ln -s "$R" .claude/skills/higgsfield-director
