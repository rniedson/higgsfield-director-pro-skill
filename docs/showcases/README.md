# Showcases

What the skill did on real requests, told from the records: the request, the steps and what each cost, what was
learned, and what changed in the skill because of it. Every number comes from a dated record, linked on each page;
the technical history stays in [`lessons-learned/`](../../lessons-learned/README.md).
