# Manual illustrations

185 schematic images used in the [illustrated manual](../README.md). They are generated by code (shapes, gradients and
geometric projections): they are not photographs or Higgsfield renders, and they do not prove how a model behaves.

| Folder | Contents | Count |
|---|---|:---:|
| `assets/` | 20 camera movement diagrams (`CAM`), 20 animations (`GIF`), 8 lighting schemes (`LGT`), 4 optics images (`OPT`), 10 sheets (`SHT`) and 3 boards (`BOARD`) | 65 |
| `atlas/` | studies of the same object, varying lens, distance and palette | 100 |
| `style/` | palette studies of 20 visual styles, in SVG | 20 |

Each folder has a catalog with the id, title, description and prompt of each image: `index.json` (for `assets/`),
`atlas.json` and `style/index.json`.

Limits: the sheets are schematic examples, not identity references; lighting and optics are teaching approximations;
the animations simplify the paths (mainly roll and crane). The exact field-of-view and focus calculation is in
`hfd.py optics`.
